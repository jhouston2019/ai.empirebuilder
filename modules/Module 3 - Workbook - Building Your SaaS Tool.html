MVP FEATURES

MVP Feature Checklist

Critical MVP Rule: If a feature takes more than 8 hours to build, it's NOT an MVP feature. Your MVP should be launchable in 7-14 days maximum. Be ruthless about cutting scope.

Core Features (Must Have for Launch)

Feature Definition Framework: Each feature should have a clear user story: "As a [user type], I want to [action], so that [benefit]."
